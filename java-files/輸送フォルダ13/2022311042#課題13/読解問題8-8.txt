応用問題１
配列memberを参照する際に利用するインデックス番号を保存したい配列であるarrayに、配列の長さが最大の自然数列をかく乱した数列を代入する。
そうすることで、ランダムに5名ずつの氏名と成績データのセットを分配する。
public int[] RandomIntOrder(int max) {
　　Random rand_1 = new Random();
　　Random rand_2 = new Random();
　　int index_1, index_2;
　　int trace = 100;
　　int[] arr = new int[max];
　　for(int i=0; i<max; i++) {
　　　　arr[i] = i;
　　}
　　do{
　　　　do{
　　　　　　index_1 = rand_1.nextInt(max);
　　　　　　index_2 = rand_1.nextInt(max);
　　　　} while(index_1 == index_2);

　　　　int buffer = arr[index_1];
　　　　arr[index_1] = arr[index_2];
　　　　arr[index_2] = buffer;
　　}while(trace-- > 0);

　　return arr;
}
