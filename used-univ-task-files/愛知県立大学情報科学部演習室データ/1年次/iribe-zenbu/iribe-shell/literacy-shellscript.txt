■■課題5■■
1から100を足し算し結果を画面上に表示するプログラムを作成せよ．
作成したシェルスクリプト，実行コマンド，実行結果を記載すること．

//作成したシェルスクリプト sigma.sh は

#!/bin/sh
echo "最大は?"
read max
echo "最小は?"
read min
sigma=0;for n in `seq $min $max`;
       do sigma=$(($sigma+$n));
       done;echo "合計は$sigma"

//実行コマンドは

shinno@shinno-HP-ProBook-430-G2:~$ sh sigma.sh

//出力結果は以下の通り。ただし100と1は標準入力であり、任意の数を代入できる。

最大は?
100 
最小は?
1
合計は5050

■■課題6■■
if 文を用い，条件 x ≧ y を満たすなら「OK」，満たさないなら｢NG」と表示するシェルスクリプトを作成し，実行せよ．
ただし，変数 x, y は第1引数，第2引数によって各値を与えるようにすること．
作成したシェルスクリプト，実行コマンド，実行結果を記載すること．

//作成したシェルスクリプトは if.sh という名前で内容は以下の通りである

#!/bin/sh

echo "第一因数は"
read x
echo "第二因数は"
read y
if [ $x -lt $y ];then
    echo "NG"
else echo "OK"
     fi

//実行コマンドは

shinno@shinno-HP-ProBook-430-G2:~$ sh if.sh

//実行結果は、途中で第一因数に5、第二因数に5を代入し

第一因数は
5
第二因数は
5
OK
