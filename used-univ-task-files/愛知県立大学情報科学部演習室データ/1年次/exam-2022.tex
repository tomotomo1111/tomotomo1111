ただし，以下の点に注意せよ：
\begin{itemize}
\item
  Beamerクラスのオプションで，アスペクト比は 16:9，フォントサイズは

\item
  墨付き括弧（例：【今日の年月日と曜日】）の部分は，
  各自にとって適切な情報に置き換えること；
% \item
%   \verb|\textcolor{【色の名前】}{【色をつけたい文字列】}|~コマンド
%   を利用すれば，文字列に色をつけることができる；
\item

  \verb|\setbeamertemplate{caption}[numbered]| を書いておけば，

% \item
%   Beamerスライドでは，\verb|thebibliography|~環境の内側に
%   \verb|\beamertemplatetextbibitems|を書いておけば，参考文献リスト
%   のカウンター（自動でつく番号）を明示できる；
\item
  Beamerスライドにおいて \verb|verb|~コマンドを使いたい場合，
  \verb|frame|~環境に \verb|fragile|~オプション を書いておく

\end{itemize}
